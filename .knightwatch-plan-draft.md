# `.knightwatch/` per-repo config — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move per-repo declarations (sibling allowlist, product context, dead-code command, strict-typing command) out of central `repos.conf` + `~/.pr-reviewer/contexts/` into each tracked repo's own `.knightwatch/` directory, read from the base branch only.

**Architecture:** One small helper (`lib/knightwatch-config.sh::read_knightwatch_file`) does `git show origin/<default>:.knightwatch/<file>` for each per-repo concern. Four call sites (`stage_search_roots` for siblings, plus 3 in `review-one-pr.sh` for product-context / dead-code / strict-typing) try `.knightwatch/` first and fall back to today's central config when the file is absent or git-show fails. Backwards-compat preserved — un-onboarded repos keep working unchanged.

**Tech Stack:** bash, git (no parser dependency — each `.knightwatch/` file is the natural format for its concern: line-oriented for siblings, markdown for context, bash for the command files).

**File structure (final state):**
- **Created:** `lib/knightwatch-config.sh` (one helper), `lib/tests/knightwatch-config-smoke.sh`
- **Modified:** `lib/search-roots.sh` (consume per-repo siblings), `lib/tests/search-roots-smoke.sh` (per-repo scenarios), `lib/review-one-pr.sh` (3 fallback-lookup patterns + new arg to `stage_search_roots`), `repos.conf` (comment updates, keep entries as fallback)
- **Dropped into each tracked repo's checkout (untracked, user commits separately):** `~/Hacking/<repo>/.knightwatch/{siblings,product-context.md,dead-code.sh,strict-typing.sh}` per the migration table in T9

Create `lib/knightwatch-config.sh`:

```bash
#!/bin/bash
# Per-repo config seam. Reads .knightwatch/<file> from the repo's base
# branch via `git show`. Trust model: base branch only — PR head edits
# don't take effect until merged.
#
# Each per-repo concern (sibling allowlist, product context, dead-code
# command, strict-typing command) gets its own file under .knightwatch/
# with the natural format for that concern (line-oriented, markdown,
# bash). No central manifest, no parser dependency.
#
# Migration model: each lookup falls back to today's central config
# (repos.conf entries, ~/.pr-reviewer/contexts/<slug>.md) when the
# .knightwatch/<file> is absent — un-onboarded repos keep working
# unchanged. Once all tracked repos have committed .knightwatch/ to
# their base branches, the fallbacks can be removed in a follow-up.

# read_knightwatch_file <repo_dir> <default_branch> <relative_path>
#   stdout: file content from origin/<default_branch>:.knightwatch/<rel>
#   exit:   0 if the file exists and was read (even if content is empty);
#           1 if the file is absent or git-show fails (caller falls back).
read_knightwatch_file() {
    local repo_dir="$1" default_branch="$2" rel_path="$3"
    git -C "$repo_dir" show "origin/${default_branch}:.knightwatch/${rel_path}" 2>/dev/null
}
```

```bash
stage_search_roots() {
    local repo="$1" repo_dir="$2" default_branch="$3"
    local sibling_repo sibling_path
    local body=""
    local included=0 missing=0
    local sibling_list

    # Source of truth for the sibling allowlist:
    #   1. .knightwatch/siblings on the base branch (per-repo, future)
    #   2. "all SOURCE_PATHS slugs except self" (legacy fallback)
    #
    # The fallback path preserves un-onboarded repos' current behavior.
    # Once every tracked repo has .knightwatch/siblings committed, the
    # fallback can be removed.
    if sibling_list=$(read_knightwatch_file "$repo_dir" "$default_branch" "siblings") && \
       [ -n "$sibling_list" ]; then
        # Per-repo allowlist: parse line-by-line, ignore blanks + # comments.
        local siblings=()
        while IFS= read -r line; do
            line="${line%%#*}"           # strip inline comments
            line="${line//[[:space:]]/}" # strip whitespace
            [ -z "$line" ] && continue
            siblings+=("$line")
        done <<< "$sibling_list"
    else
        # Fallback: all REPOS minus self
        local siblings=()
        for sibling_repo in "${REPOS[@]}"; do
            [ "$sibling_repo" = "$repo" ] && continue
            siblings+=("$sibling_repo")
        done
    fi

    for sibling_repo in "${siblings[@]}"; do
        [ "$sibling_repo" = "$repo" ] && continue
        sibling_path="${SOURCE_PATHS[$sibling_repo]:-}"
        # No SOURCE_PATHS entry = sibling not configured by operator at all
        # (not a coverage gap, just unconfigured). Skip silently.
        [ -z "$sibling_path" ] && continue
        if [ ! -d "$sibling_path" ]; then
            body+="$sibling_repo missing"$'\n'
            missing=$((missing + 1))
            continue
        fi
        body+="$sibling_repo included .siblings/$sibling_repo"$'\n'
        included=$((included + 1))
    done

    local total=$((included + missing))
    local header
    if [ "$total" -eq 0 ]; then
        header="# coverage: same-repo-only — no siblings in scope"
    elif [ "$included" -eq "$total" ]; then
        header="# coverage: full"
    elif [ "$included" -eq 0 ]; then
        header="# coverage: same-repo-only — included=0 missing=$missing"
    else
        header="# coverage: partial — included=$included missing=$missing"
    fi
    printf '%s\n%s' "$header" "$body"
}
```
